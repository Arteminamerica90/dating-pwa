# UI Coach — расширение для Chrome

Расширение отвечает на вопрос «как мне пользоваться этим инструментом?» и **показывает ответ прямо на реальном интерфейсе**: жёлтая рамка вокруг нужной кнопки, анимированный курсор, номер шага.

## Как работает

Боковую панель нужно открыть один раз — чтобы задать вопрос. Дальше ведёт сама страница.

1. Вы открываете веб-версию инструмента (After Effects, Photoshop, Figma, Canva, любой SaaS).
2. Кликаете иконку расширения, пишете: «хочу научиться делать маски в After Effects», жмёте «Показать на интерфейсе».
3. Расширение собирает **каталог элементов страницы** — до 240 кнопок, вкладок, меню и подписей с их координатами, — отдаёт его модели вместе с вашим вопросом и получает в ответ пошаговый план.
4. Дальше панель можно закрыть. На странице появляется:
   - жёлтая рамка вокруг нужной кнопки и курсор, который к ней подъезжает;
   - **карточка рядом с этой кнопкой**: номер шага, что нажать, где искать, как понять что готово, и кнопки «Далее» / «Назад»;
   - когда вы кликаете по выделенной кнопке, шаг засчитывается и происходит переход к следующему — листать руками ничего не нужно.

Ключевая идея: модель **не выдумывает селекторы**, а выбирает из реально существующих элементов страницы. Поэтому подсветка попадает в кнопку, а не мимо.

## Установка

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. «Загрузить распакованное расширение» → выберите папку `chrome-coach`.
4. Кликните иконку расширения на панели (для Chrome 116+ панель открывается автоматически).

## Настройка ИИ

Вкладка «Настройки» в панели:

| Провайдер | Когда подходит |
|---|---|
| **OpenAI** | Любой совместимый API: OpenAI, Groq, OpenRouter, YandexGPT, Together. Base URL + модель + ключ |
| **Anthropic** | Claude, для длинных и сложных объяснений |
| **Ollama** | Полностью офлайн на своей машине (`http://localhost:11434`, модель `llama3.1`) |
| **Без ИИ** | Только встроенная база инструкций |

Ключ хранится локально в `chrome.storage.local` и уходит только на указанный вами endpoint.

Ещё две галочки в настройках:

- **Озвучивать шаг голосом** — расширение проговаривает каждый шаг вслух (ru-RU). Если текст читать неудобно, можно вообще не смотреть на карточку.
- **Затемнять страницу вокруг подсветки** — гасит всё, кроме нужной кнопки.

## Режимы: онлайн и офлайн

- **Веб-версия** (`Где → Веб`) — полная работа: ИИ + подсветка элементов + анимированный курсор.
- **Настольная версия** (`Где → Настольная`) — браузер не может рисовать поверх чужого окна, поэтому ИИ выдаёт текстовые шаги с описанием, *где искать* кнопку в окне приложения, и предлагает веб-версию как альтернативу.

## Список инструментов пополняется тремя способами

**1. Вручную.** Вкладка «Инструменты» → «Добавить инструмент», затем «Добавить тему» с шагами. Такие инструкции работают без ИИ: если сеть недоступна, расширение найдёт тему по ключевым словам вашего вопроса.

**2. Автоматически по ИИ.** Спросите про инструмент, которого нет в списке, — в ответе появится карточка «Новый инструмент: …» с кнопкой добавления.

**3. Обучением на реальном интерфейсе.** Кнопка «Указать элемент мышью» → кликните по нужной кнопке. Расширение покажет найденный CSS-селектор, и вы привяжете его к шагу или сохраните как новый шаг в базе инструмента. Привязка записывается в базу знаний и в следующих сессиях применяется автоматически: модель получает готовые проверенные селекторы.

Это делает систему устойчивой к обновлениям интерфейсов: если у версии что-то переехало, вы чините один шаг, а не переписываете инструкцию.

## Структура

```
manifest.json          MV3: side panel, content script, host_permissions <all_urls>
src/background.js      service worker: сообщения, сбор контекста страницы, вызов ИИ
src/content/coach.js   каталог элементов, оверлей, карточка шага на странице, режим «указать элемент»
src/content/coach.css  стили оверлея; подсветка не перехватывает клики, карточка — перехватывает
src/sidepanel/         панель: вопрос, реестр, настройки (шаги ведёт сама страница)
src/lib/ai.js          промпт, вызов провайдеров, офлайн-фолбэк
src/lib/plan.js        нормализация ответа модели в предсказуемую схему
src/lib/registry.js    настройки, реестр инструментов, база знаний
src/data/tools.json    стартовый набор: After Effects, Photoshop, Figma, Premiere, Resolve
```

## Ограничения

- Подсветка работает только в веб-версиях инструментов: расширение видит DOM страницы, но не окна настольных приложений.
- Сайты, отрисованные целиком в canvas/WebGL, подсветку не поддерживают — там сработает текстовая инструкция.
- Каталог ограничен 800 элементами на страницу; на очень тяжёлых страницах (Figma, After Effects web) увеличьте лимит в настройках, но учтите, что растёт расход токенов.
- `host_permissions: <all_urls>` нужны для подсветки на любом сайте. Сузить список можно, если вы работаете только с конкретными сервисами.
