# WalkDate (demo PWA)

Это демо PWA-приложение знакомств, которое:
- хранит данные в IndexedDB,
- умеет включать шифрование локальных данных (AES-GCM, ключ из пароля),
- собирает геометки (куда ходил человек) через `geolocation.watchPosition`,
- считает шаги *примерно* через `devicemotion` (если доступно) или через ручной ввод,
- предлагает события только текущего города (например, Москва -> только события Москвы),
- умеет синхронизировать *зашифрованный* payload через демо-сервер.

## Запуск локально

Нужно открыть через локальный сервер (не через `file://`), чтобы работал Service Worker.

```bash
cd pwa-dating
python3 -m http.server 5173
```

Откройте `http://localhost:5173/`.

## Сервер (демо)

```bash
cd pwa-dating/server
PORT=8787 HOST=127.0.0.1 SECRET=dev-secret-change-me node server.js
```

## Где менять данные

- Список интересов и событий: `pwa-dating/events.js`
- Алгоритм определения города по координатам (demo): `pwa-dating/geo.js`
- Service Worker (offline cache): `pwa-dating/service-worker.js`
- IndexedDB/encryption: `pwa-dating/idb.js`, `pwa-dating/encryption.js`, `pwa-dating/storage.js`
- Сервер: `pwa-dating/server/server.js`

## Карта: кто рядом

1) Включите сервер и залогиньтесь в Настройках.\n
2) Включите \"Показывать меня на карте\".\n
3) Откройте вкладку \"Гео\" и нажмите \"Кто рядом\".\n

## Фильтры профиля

- Работа/вакансия: Настройки -> Работа
- Учёба: Настройки -> Учёба
- Ценности/цель: Настройки -> Ценности и цель (18+ скрыто отдельной кнопкой)\n
- Форматы общения: Настройки -> Форматы общения\n
- Здоровье: Настройки -> Здоровье (ежедневная отметка)

## Онбординг (анкета)

При первом запуске откроется мастер анкеты. Обязательные поля:\n
- имя\n
- минимум 1 фото\n
- интересы + форматы общения + ценности\n
- работа и учеба\n
- минимум 1 план на сегодня\n

Потом анкету можно изменить: Настройки -> Анкета -> Редактировать.\n

Сервер хранит только последнюю точку (в демо) и отдаёт пользователей в радиусе.

## Важно про приватность

Это демо хранит данные в `localStorage` на устройстве.
Для реального продукта нужны: явное согласие, минимизация и сроки хранения, шифрование, бэкенд с авторизацией, политика приватности.
